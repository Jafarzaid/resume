01About

Most of my job is catching delays early, getting the right people on them, and changing the plan before customers notice.

I run track-and-trace for Amazon linehaul across the UAE, Saudi Arabia, Egypt, Türkiye and South Africa, in a 24/7 NOC. A lot of that work was manual. I'm not a developer: I find the bottleneck, work out the fix, and use AI tools to build it. Those tools are now used by 40+ people and save about 1,100 hours a year.

Before this I spent nearly four years on the Alexa team in Arabic translation, QA and process improvement, where I earned my Lean Yellow Belt. I'm currently doing an MBA in Operations & Supply Chain at Jamia Hamdard.

02Selected work

i.

Faster incident handling

Problem
Handling network incidents meant a lot of repetitive data entry before anyone could work the actual problem.
What I did

ii.

Delay detection and fleet reports

Problem
Spotting unaddressed delays meant checking live trip data by hand, and the next-day dark store fleet report was built manually for three countries.
What I did
Built Excel macros with AI help that pull the trip data, flag delays and produce the report for UAE, KSA and Egypt.

92%less processing time

iii.

Break-alert extension

Problem
In a 24/7 NOC, break adherence relied on people watching the clock, and missed returns left gaps in coverage.
What I did
Created a browser extension with AI tools that alerts staff in real time when their break ends.

1,000+staff using it; break violations down to zero

I design the process and the fix; AI tools write the code. Every tool here is in daily use by my team.
